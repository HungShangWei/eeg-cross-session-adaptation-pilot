# Executed pilot source code

`candidate/` contains a release copy of the source files of the code identity that ran in the reported execution on 2026-10-27. Of the 39 Python files, 14 are byte-identical to the executed files; the other 25 differ only in neutral renames of files, modules and identifiers and, in eight of them, corrected comments. `candidate/config/RUN_CONFIG_v1.json` is a derived configuration (local paths, the run identifier and folder names replaced; non-runtime setup metadata omitted), and in the other two configuration files the author's local project path was replaced by `<PROJECT_ROOT>`. [docs/PUBLIC_SOURCE_MAP.json](../../docs/PUBLIC_SOURCE_MAP.json) lists each file's original and current SHA-256; the executed originals and the full name correspondence are kept privately by the author.

- What each file does, which copies were effective at run time, and the original versus public hashes: [docs/CODE_AND_EVIDENCE_MAP.md](../../docs/CODE_AND_EVIDENCE_MAP.md)
- How the code was run, and what a re-run would require: [docs/REPRODUCIBILITY.md](../../docs/REPRODUCIBILITY.md)
- Release file identity: [RELEASE_CODE_IDENTITY.json](RELEASE_CODE_IDENTITY.json) lists the size and SHA-256 of every file in `candidate/` of this release copy; [tools/code_identity.py](../../tools/code_identity.py) writes and checks it. Both were added outside `candidate/` after the reported execution and took no part in it; the manifest is not the original identity manifest and not an approval, and neither is covered by the licence below ([rights](../../docs/RIGHTS_AND_DEPENDENCIES.md)).
- Licence: MIT ([LICENSE](LICENSE)), covering the software, configuration files and this README in `code/pilot/`; scope and exclusions: [docs/RIGHTS_AND_DEPENDENCIES.md](../../docs/RIGHTS_AND_DEPENDENCIES.md)

The code logic is kept as it ran. It is not a packaged library, and its entry points refuse to start without the original environment, paths, identity manifest and a local approval record. Comments and docstrings that read as if the code had not yet run were corrected; constants and flags written during code preparation (for example `publishable_as_pilot_results=False`) were left unchanged because they are code. They do not describe the reported execution, which ran this code on real data. Internal labels such as `PREP`, `grant` and `B2R` are explained in the [code map](../../docs/CODE_AND_EVIDENCE_MAP.md#internal-labels-you-will-meet-in-the-code).
